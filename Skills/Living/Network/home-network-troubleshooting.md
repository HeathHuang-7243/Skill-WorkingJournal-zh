# 家庭网络排障（Wi-Fi / DNS / 设备）

> 示例 —— Living 领域排障技能的脱敏模板。把工具和细节换成你自己的设置。个人标识符（订阅、账号邮箱、RFC1918 示例之外的私有 IP）绝不进文件。

## 诊断流程（按顺序执行 —— 最快优先）
- [ ] **先检查调制解调器/路由器**：断电重启一次；互联网灯亮吗？这能清除最高频的问题。
- [ ] **测试另一台设备**：如果其他设备正常，问题在设备，不在网络。
- [ ] **检查单设备 Wi-Fi**：忘记网络 → 重新加入；检查设备在 2.4 GHz 还是 5 GHz（墙对 5 GHz 阻隔更大）。
- [ ] **检查 DNS**：`nslookup <域名>` 或把设备切到公共/DoH 解析器——"能 ping 通 IP 但网站打不开"是经典的 DNS 污染特征。
- [ ] **检查局域网共享**：确认设备在同一子网；配置了过期网关/静态 IP 的客户端无法访问共享服务。
- [ ] **检查路由器规则**：家长控制、MAC 过滤或"访客网络"设置可以静默阻塞一台设备。

## 踩坑 / 教训
- "重启路由器"修复的问题比任何深层设置都多——动配置前先重启。
- 只有一台设备 Wi-Fi 掉线而其他正常 = 设备电源管理或信道竞争，不是 ISP 的问题。
- DNS 问题看起来像"网络断了"：责备连接性之前，永远先排除 DNS。
- 对局域网共享，手工设置的、落在 DHCP 范围之外的静态 IP 是经典的静默破坏者。
