# 团队路由（职责与联系人）

> 这是**参考/路由知识**，不是可执行的技能。当有人问"这个归谁"并且你需要快速找到联系人时使用。
> *决策流程*（分类 / 定范围 / 转交或协作 / 自行处理或升级）在 [`work-triage.md`](./work-triage.md)；本表只回答"谁负责什么"。

## 交互模型（工作如何到达你这里）
- 你通常**不**直接与应用团队沟通。他们的请求通过 **IT 请求系统**到达你这里。
- 当需要持续协作时，他们也会**为你开工单**。
- 所以：本表路由的是*内部归属*，不是与应用团队的直接联系。

## 踩坑 / 教训
- 本文件可能包含**真实姓名**——如果这样，请保持仓库私有；任何公开推送前先脱敏。
- 路由表是*内部*归属；应用团队的请求走 IT 请求系统，不走本表。
- 其他 Tower 拥有的条目（work-triage ② 情况 3）= 路由给该 Tower 的负责人，**不是你的范围**；你只是协作方。
- 你自身可执行的技能（架构 / 自动化 / 策略 / 迁移）是**独立的技能文件**，不是本表的行。
