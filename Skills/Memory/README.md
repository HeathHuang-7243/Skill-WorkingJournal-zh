# Memory

本文件夹存放本仓库的项目记忆——每日记录什么变了、为什么变。

## 规则

1. **文件命名：** 每天一个文件，`YYYY-MM-DD.md`（例如 `2026-08-05.md`）。同一天的内容追加到同一文件；绝不一天建多个文件。
2. **强制同步：** 本仓库内的任何变更——新增 / 修改 / 移动 / 删除 / 重构 / 规则更新——都必须*在当天*追加到当天文件。
3. **内容：** 记录有持久价值的东西——已完成的工作、技术决策、用户偏好、踩过的坑。不要记录一次性/临时的信息（搜索结果、临时路径、工具报错）。
4. **读取：** 未来会话和模型应读取这些文件以加载项目上下文——而不是全局记忆位置。
5. **蒸馏：** 超过 30 天的日志可以按月份/主题浓缩进 `MEMORY.md`（可选），然后删除旧日志文件。

## 模板

每天首次使用时复制 `_TEMPLATE-YYYY-MM-DD.md`。
