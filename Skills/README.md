# Skills

本仓库用于保存你的技能——可复用的流程、判断过程和运维手册，每个技能是一个独立的 markdown 文件，人类或 AI 模型都可以路由到它。

**模型 / 代理：** 从 [`index.md`](./index.md) 开始——这是把触发词映射到正确技能文件的路由目录。

## 工作方式说明

- 请求可能以邮件或聊天线程的形式附来。把它们当作主要的事件输入，提取可操作的字段（环境、范围、错误文本、时间戳、负责人），然后通过 `index.md` 的触发词路由。
- 本仓库内的任何操作（新增 / 修改 / 移动 / 删除 / 重构 / 规则更新）都必须同时写入 `Memory/YYYY-MM-DD.md` 的当日记录。
- 决定是新建技能还是扩展现有技能时，使用 [Working/skill-creation-rubric.md](./Working/skill-creation-rubric.md)。

# Memory

本仓库的项目记忆存放在 **`Memory/`**（仓库本地，不是全局的 `.workbuddy/memory/`）。

## 约定（给其他模型 / 未来会话遵循）

1. **读取：** 当你需要回忆过去的工作、决策或上下文时，直接读取 `Memory/` 下的文件。
2. **新条目：** 按日期创建文件，命名为 `YYYY-MM-DD.md`（例如 `2026-08-05.md`）。同一天的内容追加到当天的文件；不要一天建多个文件。
3. **强制同步：** 本仓库内的任何新增 / 修改 / 移动 / 删除 / 重构 / 规则更新，都必须作为一条记录追加到当天记忆文件。
4. **内容：** 记录有持久价值的东西——已完成的工作、技术决策、用户偏好、踩过的坑。不要记录一次性/临时的信息（搜索结果、临时路径、工具报错）。
5. **长期蒸馏：** 超过 30 天的日志可以按月份/主题浓缩进 `MEMORY.md`（如果你创建它），然后删除旧的日志文件。

├── Memory/
│   ├── README.md             # 本指南
│   ├── MEMORY.md             # （可选）长期浓缩笔记

│   └── 2026-08-03.md

    ├── _TEMPLATE.md
