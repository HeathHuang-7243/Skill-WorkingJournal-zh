# Archive/

已关闭的工作，按项目归档。记录实际交付了什么——参考记忆。

## 约定
- **每个项目/项目一个文件夹** —— 例如 `Archive/<项目-2026>/`，可选子文件夹（`预算`、`设计`、`排障`）。
- **从 `active/` 移到这里**：项目关闭时；保留整个文件夹供未来参考。
- **记录移动日志**：移动当天在 `daily/<YYYY-MM-DD>.md` 中记录。

## 规则
- 归档材料是只读参考——不要就地编辑；新工作在 `active/` 或 `daily/` 中开展。
- 如果归档的产出日后变成可复用流程，把它提炼成 `Skills/` 中的技能文件，而不是只留在这里。
