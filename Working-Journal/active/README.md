# active/

进行中的工作，每个主题一个文件夹：事件 / 项目 / 项目流。

## 约定
- **每个主题一个文件夹** —— 例如 `active/<客户或主题>/`，或一个主题有多个流时用 `active/<主题A>/<子主题>/`。
- **内容：** 工作文件、草稿、证据（日志、截图）、准备好的产出（例如起草的邮件）——该主题在开放期间需要的一切。
- **关闭时移入 Archive：** 项目结束时，把整个文件夹移到 `Archive/<项目>/`，并在 `daily/<日期>.md` 中记录日志。

## 规则
- 草稿放在这里；打算复用的最终产出放到 `Skills/Working/Artifacts/<skill-id>/`（遵循 Skills 仓库约定）。
- 每一步都要记录到 `daily/<YYYY-MM-DD>.md`，带相对路径。
